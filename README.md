# 🍬 Sweet Dash

A fun and simple browser-based game where players control a character and try to avoid obstacles while achieving the highest score!

## 🎮 About the Game

Sweet Dash is a small game built using HTML, CSS, and JavaScript. The player needs to navigate through obstacles and survive as long as possible.

## ✨ Features

- Simple and fun gameplay
- Score tracking
- Interactive controls
- Colorful game design
- Play directly in the browser

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Play

1. Open the game in your browser.
2. Use the game controls to move the character.
3. Avoid the obstacles.
4. Try to achieve the highest score!
